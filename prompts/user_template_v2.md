Запрос оператора сервиса:
{query}

Если запрос относится к каталогу пользователей User Directory, вызови tool user_directory_api не больше одного раза.
Затем верни ровно четыре строки без пустых строк между ними.
В строку Data скопируй объект body из ответа tool. Не подставляй {}, если tool уже вернул body.
